# Tic Tac Toe

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript. The game allows two players to play against each other with automatic win and draw detection.

## 🎮 Features

* Two-player gameplay
* Interactive game board
* Turn tracking for X and O
* Automatic win detection
* Draw detection
* Game reset functionality
* Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML5 – Structure
* CSS3 – Styling and layout
* JavaScript – Game logic and interactivity

## 📂 Project Structure

```text
Tic-Tac-Toe/
├── index.html
├── style.css
└── script.js
```

## 🎯 Purpose

This project was created to practice HTML, CSS, JavaScript, DOM manipulation, event handling, and basic game logic.
